# LINE オープンチャット IPトラッカー v1.1 (line_iptool.py)

オープンチャットの参加者・特定ユーザーにリンクを踏ませて、
**接続元IPアドレス / 回線種別 / おおよその地域 / 端末情報** を記録するツールです。

> ⚠️ 本ツールは許諾されたセキュリティ調査・ 自己のコミュニティ運営のための利用を想定しています。
> 得られたIPからの「個人の割り出し」は本人特定法・不正アクセス禁止法・プロバイダ責任制限法の
> 観点で制約があり、安易な開示請求・特定行為は法的リスクを伴います。自己責任で利用してください。

---

## セットアップ

1. `cloudflared.exe` を同じフォルダに置く (同梱 or 下記から取得)
   https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
2. Python 3.10+ があれば追加インストールは不要 (標準ライブラリのみ)

## 使い方 (基本)

```
cd C:\Users\admin\LINE-Tools\ipfinder
python line_iptool.py --tunnel --tokens u1,u2
```

- 起動すると `https://xxxx.trycloudflare.com/u1` のような公開URLが表示される
- `links.txt` にコピペ用メッセージ付きで保存される
- ダッシュボード: 表示される `http://127.0.0.1:8080/?k=xxxx` をブラウザで開く
  (リアルタイムでヒットが追加される)

## 1人ずつ個別に特定する場合

```
python line_iptool.py --tunnel --tokens userA,userB,userC
```

- `userA` 用のリンクをターゲットAだけにDMで送る、のように使う
- 誰がどのリンクを踏んだかで、対象をピンポイントに識別できる

## ページ偽装オプション

| オプション | 効果 |
|---|---|
| `--page survey` | アンケート風ページ (デフォルト) |
| `--page news` | お知らせページ風 |
| `--page memo` | メモ/資料ページ風 |
| `--no-geo` | GeoIP問い合わせなし (完全ローカル動作) |
| `--public-url URL` | ngrok など自分のトンネルURLを使用 |
| `--port N` | ポート指定 (既定 8080) |
| `--reset` | 過去の記録を削除して開始 |

## v1.1 の新機能

- **検証の色分け**: ターミナルとダッシュボードで判定を色分け表示
  - 緑 `検証OK` : WebRTCで取得したグローバルIP = 接続元IP (実端末とほぼ確定)
  - 黄 `IP相違` : 両者が不一致 (VPN/プロキシ/二重NATの可能性)
  - 水 `v4/v6併用` : IPv4とIPv6の併用で不一致に見えるだけ
  - 灰 `未検証` : WebRTC未取得 (LINE内蔵ブラウザ等)
  - 赤 `BOT?` : リンクプレビュー等の自動アクセス
- **GeoIP のターミナル表示**: ヒット直後に `├ Geo :` 行で地域/ISP/回線種別を表示
- **回答の送信**: アンケートページで選択肢を選んで「回答を送信する」ボタンを押すと
  実際に `POST /api/answer` で送信され、回答内容 (`Q1=... / Q2=... / コメント「...」`)
  がターミナル・ダッシュボード・hits.jsonl に記録される

## 記録される内容

- 接続元IP (LINEアプリ内ブラウザ / 外部ブラウザ問わず)
- GeoIP: 国/都道府県/市/ISP/モバイル回線判定/VPN・DC判定
- WebRTC (STUN): ルーター越えのグローバルIP候補とローカルIP
- 端末: UA / 言語 / タイムゾーン / 画面解像度 / ネットワーク種別
- どの追跡リンク経由か (token)
- LINE内蔵ブラウザか、リンクプレビューbotかの自動判定

## 記録ファイル

- `hits.json`  … ダッシュボード用 (再起動で読み込み)
- `hits.jsonl` … 追記型の生ログ
- `links.txt`  … 配布リンクとコピペ用文面

## コツ / 注意

- リンクプレビュー (LINEbot) が先にアクセスする場合がある → ダッシュボードで
  `bot` タグの付いたヒットは本人ではない可能性が高い
- モバイル回線はIPが頻繁に変わる → 同一人物の再訪でIPが変わることがある
- VPN/プロキシ使用時は GeoIP が実所在地とずれる (`DC/VPN` タグで検出)
- LINE内蔵ブラウザは WebRTC が無効な場合がある → その場合は接続元IPのみ
- トンネルURLは起動のたびに変わる
